# MCUI 前端设计

前端以多节点运维为主。管理员登录后先看总览，从节点列表处理接入和 Core 生命周期，从代理配置页修改入站、出站和路由。客户端订阅提供独立的管理页和领取页。

## 当前面板

- 登录后显示总览。总览和节点列表在前台时定期刷新心跳。节点列表分页显示 Agent 心跳和在线状态，并通过现有接口为当前页可管理的在线节点读取 Xray 版本与运行状态。节点列表的「管理 Core」打开抽屉，任务历史和 Agent / Helper 成对更新在「设置 → 任务」。
- 「代理配置 → 入站」支持现有受控授权草稿。保存后由节点预览，面板可对照当前与拟应用授权，核对候选 SHA-256 后确认下发。面板以成功任务及节点上报的对应修订确认生效。出站和路由标签页显示待接入提示。
- 「客户端订阅」按节点、用户名和状态查找用户。刚签发的链接在当前管理会话的节点页面内可复制并生成二维码，关闭分享弹窗后可重新打开。切换节点、刷新页面或重新登录后，已有链接的正文需等待后端支持读取。节点分享可选客户端及已授权入站，领取链接待接入。
- 用户通过 HTTPS 打开订阅页，在页面内复制链接、显示二维码或生成 Xray 配置。二维码在浏览器中生成。订阅令牌在读取后从地址栏移除，链接和配置凭据仅保存在页面内存。在同一标签页打开订阅链接会重新验证授权。接口未细分失效原因时，页面提示订阅失效或授权暂不可用。

## 侧栏和总览

- **总览**是登录后的默认页，显示在线、离线和待接入节点，并提供访问节点列表的快捷入口。
- **节点管理**下常驻三个入口。**节点列表**负责节点接入和 Core 管理，**代理配置**负责入站、出站和路由，**客户端订阅**负责签发和分享。
- **设置**放在侧栏底部，默认折叠，包含**审计日志、Core 版本、任务、管理员**。Core 版本页收纳官方版本目录和主控备用制品，任务页用于查询历史记录。

桌面端固定侧栏，窄屏通过菜单按钮打开侧栏。当前页在侧栏高亮。从节点列表打开代理配置或客户端订阅时带上该节点，在相关页面之间切换时沿用，页面顶部显示节点名称并提供切换入口。

## 节点列表和 Core 管理

节点表格显示节点名、分组、Agent 心跳及在线状态，以及已安装 Core 的版本和运行状态。Agent 是否在线和 Core 是否运行各自显示。列表按分组和状态筛选，添加节点放在页头，生成安装命令放在对应节点的行操作中。

每行的「管理 Core」打开右侧抽屉，展示该节点上的 Core 状态、版本和最近一次操作结果。安装、启停、升级、降级和卸载都从抽屉发起。版本变更时显示当前版本和目标版本，操作提交后在抽屉里跟踪结果。行操作也提供「代理配置」和「分享」入口。

## 代理配置

代理配置页的页头显示当前节点、Core、已生效修订和草稿状态。Xray 配置分为三个标签页，共用同一份草稿。

| 标签页 | 页面内容 |
| --- | --- |
| 入站 | 列出入站名称、协议、监听端口和用户授权，点一行查看或编辑详情。 |
| 出站 | 列出出站名称、协议、目标和路由引用，标明默认出站。改名或删除时提示受影响的规则。 |
| 路由 | 按匹配顺序展示规则，每行显示匹配条件和目标出站。支持调整顺序，目标从当前草稿的出站中选择，并显示未命中规则时使用的出站。 |

Xray 从上到下匹配路由规则，采用第一条命中的规则。全部未命中时，使用出站列表的第一项。预览同时展示规则顺序和默认出站的变化。 [Xray 路由](https://xtls.github.io/config/routing.html#routingobject) · [Xray 出站](https://xtls.github.io/config/outbound.html#outboundobject)

三个标签页共用「保存草稿」「预览变更」「下发配置」。新增出站和引用该出站的规则可以分开编辑，一起预览并下发。只有任务成功且节点上报相应修订后，界面才标记为已生效。现有配置流程覆盖节点预先批准的受控入站及用户授权，通用出站和路由编辑仍待实现，受节点策略和 Core 能力约束。 [受控入站配置流程](./phase-4-xray-inbound.md#面板管理入站与授权) · [配置策略](./config-policy.md)

## 客户端订阅

### 管理员列表

参考 3x-ui 的客户端列表和分享交互。页头放节点选择、用户名搜索和订阅状态筛选。表格显示客户端、已授权入站、订阅状态和到期时间。有有效链接时，行尾直接提供「复制订阅」和「二维码」，点击用户名可打开分享弹窗。未签发时显示「签发链接」，轮换和撤销放入更多操作。 [3x-ui 客户端列表](https://github.com/MHSanaei/3x-ui/blob/main/frontend/src/pages/clients/ClientsPage.tsx)

### 分享弹窗

分享弹窗分为「订阅链接」和「节点分享」两个标签。两个标签都显示链接、有效状态、复制按钮和二维码。也可以从节点列表的「分享」打开同一弹窗，自动带上当前节点，再选择用户和入站。 [3x-ui 分享弹窗](https://github.com/MHSanaei/3x-ui/blob/main/frontend/src/pages/clients/ClientQrModal.tsx)

| 链接 | 范围 |
| --- | --- |
| 订阅链接 | 获取该用户在当前节点已生效的授权配置。 |
| 节点分享链接 | 领取指定节点、入站和用户对应的单项配置。逐项提供复制和二维码。 |

**授权管理员在链接有效期间可以随时查看、复制和生成二维码。** 关闭弹窗、刷新或重新登录后，仍然打开同一条链接。查看、复制和扫码复用已签发链接，轮换才生成新链接。过期或撤销时显示相应状态和重新签发入口。

### 用户订阅页

用户打开链接进入独立的订阅页。页首展示订阅名称、状态和到期时间，下方按「订阅链接」「可用配置」「使用帮助」组织。配置列表显示获准的节点、入站和协议。手机端优先展示状态和主操作，二维码和链接放在同一操作区。 [3x-ui 用户订阅页](https://github.com/MHSanaei/3x-ui/blob/main/frontend/src/pages/sub/SubPage.tsx) · [3x-ui 配置列表](https://github.com/MHSanaei/3x-ui/blob/main/frontend/src/pages/sub/SubConfigsTab.tsx)

当前受控入站的主操作为「生成并下载 Xray 配置」。用户选择获准的入站，输入节点管理员交付的密码，浏览器在本地生成 Xray JSON。支持直接导入的客户端和格式接入后，再在同一位置提供导入动作。流量和额度仅在对应 Core 已有可靠计量时展示。 [MCUI 客户端订阅流程](./phase-4-xray-inbound.md#客户端订阅)

### 链接查看所需的后端能力

现有订阅令牌仅在签发时展示一次，主控保存摘要。重复查看需要增加按权限读取有效链接的能力。可在保留令牌摘要用于校验的同时，加密保存新发令牌供有权管理员读取。历史摘要无法还原，旧链接需要在轮换后才能重复查看。节点分享链接还需要按节点、入站和用户验证领取范围。 [现有令牌行为](./phase-4-xray-inbound.md#客户端订阅)

订阅仍以节点已应用修订和用户授权判定有效性，保留到期、轮换、撤销和修订变化后的失效规则。撤销链接会停止后续领取，已下载配置的连接权限通过入站授权或节点凭据管理。

## 界面样式与目标验收

管理端采用深灰底色、蓝色主操作和带文字的侧栏图标。总览使用少量状态卡，节点、订阅、任务和审计统一使用表格。用户订阅页沿用 MCUI 的字体和配色，在较窄的单栏内集中展示状态、链接和配置。

- 登录后进入总览，节点列表和代理配置可从侧栏直接打开，「设置」可展开四项入口。
- 在节点列表和 Core 抽屉中可查看 Agent 和 Core 各自的状态并执行获准的 Core 操作。
- 在代理配置的三个标签间编辑后，可预览同一份草稿，并将节点回报的生效修订与草稿状态分开展示。
- 签发后重新登录，仍能查看并复制相同的有效订阅链接和节点分享链接。轮换后旧链接失效，读取链接时按管理员的节点授权范围校验。
- 手机端可以查看失效原因、复制有效链接、显示二维码和下载已授权的配置，长链接和摘要在内容区内折行或截断。
